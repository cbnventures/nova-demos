# Installation

<Terminology title="Protocol translator and relay engine between systems" to="/docs/terminology#envoy">Envoy</Terminology> ships as a 3MB <Terminology title="Container image format Envoy ships as" to="/docs/terminology#vial">Vial</Terminology> image with zero external dependencies. Choose the deployment method that fits your infrastructure.

## Prerequisites

| Requirement                                                                                                                    | Minimum Version | Notes                                                     |
|--------------------------------------------------------------------------------------------------------------------------------|-----------------|-----------------------------------------------------------|
| **<Terminology title="Container image format Envoy ships as" to="/docs/terminology#vial">Vial</Terminology>**                  | 4.0             | Recommended for production. Compose v2 for stack deploys. |
| **<Terminology title="CLI used to install and run Envoy" to="/docs/terminology#spark">Spark</Terminology>**                    | 2.1             | Alternative CLI-based deployment.                         |
| **<Terminology title="Orchestrated cluster deployment target for Envoy" to="/docs/terminology#trellis">Trellis</Terminology>** | 1.8             | Orchestrated deployment across clusters.                  |

## Install

<Tabs>
<TabItem value="vial" label="Vial" default>

Pull the image from the registry:

```bash title="Pull and run with Vial"
vial pull envoy:latest
vial run -d \
  --name envoy \
  --restart unless-stopped \
  -p 8090:8090 \
  envoy:latest
```

Verify the container is running:

```bash
vial logs envoy
# [envoy] Starting on port 8090
# [envoy] Cipher: ready
# [envoy] Courier: ready
# [envoy] Health check: OK
```

</TabItem>
<TabItem value="spark" label="Spark CLI">

Install the <Terminology title="Protocol translator and relay engine between systems" to="/docs/terminology#envoy">Envoy</Terminology> CLI globally:

```bash title="Install with Spark"
spark install envoy
```

Start the <Terminology title="Single declared pipeline from a source to destinations" to="/docs/terminology#relay">relay</Terminology> server:

```bash
envoy start --port 8090
```

Or with explicit configuration:

```bash
envoy start --config relay.grain --port 8090
```

</TabItem>
<TabItem value="trellis" label="Trellis">

Deploy to a <Terminology title="Orchestrated cluster deployment target for Envoy" to="/docs/terminology#trellis">Trellis</Terminology> cluster using the <Terminology title="Config file declaring every relay Envoy runs" to="/docs/terminology#relay-manifest-grain">manifest</Terminology>:

```text title="envoy.trellis.grain"
deployment "envoy" {
  image    = "envoy:latest"
  replicas = 2
  port     = 8090

  resources {
    memory = "32Mi"
    cpu    = "50m"
  }

  health {
    path     = "/health"
    interval = "10s"
  }
}
```

Apply the deployment:

```bash title="Deploy to Trellis"
trellis apply envoy.trellis.grain
```

</TabItem>
</Tabs>

:::tip Minimal Footprint
The <Terminology title="Protocol translator and relay engine between systems" to="/docs/terminology#envoy">Envoy</Terminology> <Terminology title="Container image format Envoy ships as" to="/docs/terminology#vial">Vial</Terminology> image is 3MB. That is not a typo. Zero external dependencies means zero bloat. Cold starts complete in under 200ms, and the attack surface is limited to code we wrote and you can audit.
:::

## Post-Install Verification

Regardless of deployment method, verify the <Terminology title="Single declared pipeline from a source to destinations" to="/docs/terminology#relay">relay</Terminology> is operational:

```bash title="Health check"
curl http://localhost:8090/health
```

Expected response:

```json title="Health check response"
{
  "status": "healthy",
  "version": "2.1.0",
  "uptime_seconds": 12,
  "components": {
    "cipher": "ready",
    "parcel": "ready",
    "dispatch": "ready",
    "courier": "ready",
    "ledger": "ready"
  }
}
```
