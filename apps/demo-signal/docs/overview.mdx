# Signal

Signal is an attribution engine that traces how intent travels — from first encounter to final action. Every link is a sensor, every redirect is a data point — Signal shows you what was clicked, why it was clicked, and what almost happened instead.

> "The shortest distance between a click and an insight is a link that knows where it has been."

## What Signal Does

Most analytics tools count events after the fact. Signal instruments the path itself — each link minted through Signal carries embedded attribution metadata that survives URL shortening, messaging apps, private browsing, and cross-device handoffs.

When a conversion happens, Signal reconstructs the full journey — every <Terminology title="Single tracked interaction within an attribution path" to="/docs/terminology#touchpoint">touchpoint</Terminology>, every hesitation, every channel that contributed.

| Tool                                                                                                                                   | Purpose                                                                                                                                                                                                               |
|----------------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **<Terminology title="Short link carrying embedded attribution metadata" to="/docs/terminology#beacon">Beacon</Terminology>**          | Link minting engine — branded short links with embedded attribution metadata.                                                                                                                                         |
| **<Terminology title="Signal's multi-touch attribution engine tracing conversions" to="/docs/terminology#prism">Prism</Terminology>**  | <Terminology title="Credits every touchpoint across the full conversion path" to="/docs/terminology#multi-touch-attribution">Multi-touch attribution</Terminology> modeler — traces conversion paths across channels. |
| **<Terminology title="Signal's real-time click stream capturing interactions" to="/docs/terminology#pulse">Pulse</Terminology>**       | Real-time click stream — live feed of interactions, geo, device, and referrer.                                                                                                                                        |
| **<Terminology title="Point-in-time campaign performance snapshots over time" to="/docs/terminology#aperture">Aperture</Terminology>** | Campaign snapshots — point-in-time performance captures with comparison overlays.                                                                                                                                     |
| **<Terminology title="Detects overlap between audience segments" to="/docs/terminology#resonance">Resonance</Terminology>**            | Audience overlap detector — finds where audiences bleed into each other.                                                                                                                                              |
| **<Terminology title="Generates QR codes and deep links with attribution" to="/docs/terminology#flare">Flare</Terminology>**           | QR and deep link generator — physical-to-digital bridge with full attribution.                                                                                                                                        |

:::info
Signal operates at the link level. Other attribution platforms bolt tracking onto pages. Signal embeds it into the links themselves — so attribution data exists before the page even loads.
:::

## How It Works

A <Terminology title="Short link carrying embedded attribution metadata" to="/docs/terminology#beacon">Beacon</Terminology> link is not just a redirect. It encodes the campaign, the channel, the variant, and a unique <Terminology title="Unique identifier tying touchpoints into one path" to="/docs/terminology#trace">trace</Terminology> identifier.

When the link is clicked, <Terminology title="Signal's real-time click stream capturing interactions" to="/docs/terminology#pulse">Pulse</Terminology> captures the interaction in real time. When the user eventually converts, <Terminology title="Signal's multi-touch attribution engine tracing conversions" to="/docs/terminology#prism">Prism</Terminology> walks the full attribution path backward and distributes credit across every <Terminology title="Single tracked interaction within an attribution path" to="/docs/terminology#touchpoint">touchpoint</Terminology>.

```text
Beacon mints link → User clicks → Pulse captures event
  → User clicks again from a different channel → Pulse captures
    → User converts → Prism reconstructs the full path
      → Aperture snapshots the campaign state at conversion time
```

## When to Use Signal

- **Campaign attribution** — trace which channels, links, and <Terminology title="Single tracked interaction within an attribution path" to="/docs/terminology#touchpoint">touchpoints</Terminology> drive conversions.
- **Audience intelligence** — detect overlap between campaigns and <Terminology title="Named audience defined by conditions on click data" to="/docs/terminology#segment">segments</Terminology> with <Terminology title="Detects overlap between audience segments" to="/docs/terminology#resonance">Resonance</Terminology>.
- **Real-time monitoring** — watch click streams arrive live with <Terminology title="Signal's real-time click stream capturing interactions" to="/docs/terminology#pulse">Pulse</Terminology>.
- **Physical-to-digital** — bridge print, out-of-home, and events to digital attribution with <Terminology title="Generates QR codes and deep links with attribution" to="/docs/terminology#flare">Flare</Terminology>.
- **<Terminology title="Clicks arriving with no referrer or UTM data" to="/docs/terminology#dark-traffic">Dark traffic</Terminology> recovery** — recover attribution for clicks that strip referrer and UTM data.
