# Bare Sample

This page renders with the full site chrome, like every other page. Append `?docusaurus-data-bare=true` to its URL and the navbar, footer, announcement bar, sidebar, breadcrumbs, table of contents, tags, and pagination all disappear — what remains is the title, the content you are reading, and the last-updated line at the bottom. Try it: <a href="?docusaurus-data-bare=true" target="_blank" rel="noopener noreferrer">view this page in embed mode</a>. Removing the parameter from the URL brings the chrome right back.

## Why Bare Mode Exists

Bare mode exists for pages that need to live inside another surface. Mobile and desktop apps often embed Terms of Service, Privacy Policy, or licensing pages in a webview, and rendering the full site chrome inside that webview looks broken — it invites the reader to wander into navigation the host app never meant to expose.

## One Page, Both Worlds

With bare mode, one MDX file serves both worlds. The host app points its webview at the page URL with the parameter appended and gets a clean, purpose-built document, while the site keeps a single source of truth for the content instead of maintaining a separate stripped-down copy.

## How It Works

Nothing about this page is special — a tiny inline script maps `docusaurus-data-*` query parameters to `data-*` attributes on the page before the first paint, and a stylesheet keyed off the `data-bare` attribute hides the chrome, so the same parameter works on any page of this site without a flash of the full layout.

## What You Are Looking At

The headings on this page also give the table of contents something to show: with the chrome present, the section list renders in the right rail, and in embed mode it disappears along with everything else. If you are reading this without a table of contents, a navbar, or a footer, the parameter is doing its job.
