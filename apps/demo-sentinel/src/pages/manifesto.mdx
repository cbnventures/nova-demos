# Manifesto

Sentinel exists because the perimeter died and nobody updated the assumptions. We believe trust is a vulnerability, not an asset. Every granted session is a liability. Every static rule is a blind spot. Security is not a gate you pass through once — it is a continuous evaluation that never concludes.

## Trust as Liability

The traditional model grants trust at the door and never revisits the decision. That model assumes the world inside is safe. It is not. Conditions change between the moment access is granted and the moment it is used. The device drifts. The network shifts. The session ages. A system that does not re-evaluate is a system that remembers a past that no longer exists.

## Verification Over Permission

Permission is a snapshot. Verification is a discipline. We verify posture, identity, context, and behavior — not once, but continuously. The access decision made ninety seconds ago is not the access decision now. We make it again, because the inputs have changed and the answer might have changed with them.

## Walls Within Walls

A single breach should not grant the run of the house. We segment by default, so that a compromised workload reaches only itself. Lateral movement is the attacker's payoff for a single mistake. We eliminate the payoff.

### Why simulation precedes enforcement

A policy that surprises the people it governs is a policy that gets bypassed. We test every rule against real traffic before it touches production, because the cost of a misconfigured policy is indistinguishable from the cost of no policy at all.

## The Ledger That Cannot Lie

Every access decision, every policy evaluation, every connection is recorded. An immutable audit trail is not a compliance checkbox — it is the mechanism that makes continuous verification accountable. When a session is reconstructed months later, the record must say exactly what happened, not what the system wishes had happened. Trust decisions that cannot be audited are trust decisions that cannot be challenged.
