Lantern 2.4 发布了两项让住宅更易理解、评估更快速的功能：Lens 平面图叠加——将区域图渲染到实际平面图上，以及 Beacon 增量运行——仅重新评估发生变化的传感器。两者即日可用。

{/* truncate */}

## Lens 平面图叠加

Lens 一直以来都会构建区域图——住宅如何划分区域、哪些传感器监视哪些区域、存在感如何在区域之间流转的逻辑映射。此前，这张图以区域名称和边的列表形式存在。有用，但抽象。

平面图叠加让区域图变得具象。上传一张平面图图片，标记每个区域的角点，Lens 就会将区域图直接渲染到平面图上。传感器覆盖区域变成阴影区域，存在感转移变成可见的箭头，盲区——没有传感器覆盖的区域——会被自动高亮。

```json title="平面图配置"
{
  "floorPlan": {
    "image": "/plans/main-floor.png",
    "zones": {
      "kitchen": { "corners": [[120, 40], [320, 40], [320, 200], [120, 200]] },
      "hallway": { "corners": [[320, 80], [400, 80], [400, 160], [320, 160]] },
      "porch":   { "corners": [[400, 60], [520, 60], [520, 180], [400, 180]] }
    }
  }
}
```

叠加层实时更新。当传感器触发时，其区域在平面图上亮起。当存在感从一个区域转移到另一个区域时，箭头会脉动。住宅变成了你可以观看的东西，而不仅仅是你在日志中阅读的内容。

### 盲区检测

叠加层最直接有用的部分是盲区检测。平面图上任何落在所有传感器覆盖多边形之外的区域都会以警告色着色。这些是住宅感知中的空白——有人可以在 Lantern 不注意的情况下移动的地方。

## Beacon 增量运行

Beacon 评估整个住宅的传感器状态并确定整体安全态势。此前，每次评估都是完整运行——每个传感器重新读取，每个区域重新评分，每次转移重新检查。对于有 40 个传感器的住宅，一次完整运行大约需要 3 秒。作为定期任务没问题。作为变更响应则太慢。

增量运行解决了这个问题。当单个传感器触发时，Beacon 仅重新评估该传感器所属的区域和直接相连的区域。其他一切从上次运行结果中延续。

```text title="增量运行耗时（40 传感器住宅）"
完整运行:     3.1s   (40 个传感器, 12 个区域)
增量运行:     0.2s   (3 个传感器, 2 个区域)
```

结果相同——一份完整的态势快照——但路径更短。门廊运动传感器触发，Beacon 在 200 毫秒内更新门廊区域和走廊区域，而不是重新读取厨房、卧室和每个没有变化的传感器。

### 完整运行何时仍会发生

增量运行不会取代完整运行。Beacon 仍按可配置的间隔（默认：每 5 分钟）执行一次完整运行，以捕获偏移——停止报告的传感器、电量降至阈值以下的电池、因为没有事件发生而分数衰减的区域。增量运行处理快速路径，完整运行处理完整路径。

## 升级

Lantern 2.4 向后兼容。Lens 平面图叠加是可选功能——没有平面图图片的住宅继续使用列表视图。Beacon 增量运行默认对所有住宅启用。

```text title="升级"
lantern update
lantern --version
# lantern 2.4.0
```
