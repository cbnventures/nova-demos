# API Reference

The <Terminology title="Whole-house monitoring toolkit signaling with warm light" to="/docs/terminology#lantern">Lantern</Terminology> <Terminology title="Small HTTP API Lantern exposes for zones and events" to="/docs/terminology#spoke">Spoke</Terminology> API is small on purpose. Most households never need it.

## Base URL

```text
https://lantern.local/api
```

## Endpoints

| Method | Path                      | Description                                                                                                                                                                                                                                                                                                                                                                                         |
|--------|---------------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `GET`  | `/api/zones`              | List every <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zone</Terminology> <Terminology title="Whole-house monitoring toolkit signaling with warm light" to="/docs/terminology#lantern">Lantern</Terminology> is <Terminology title="General term for an active monitoring session" to="/docs/terminology#watch">watching</Terminology>. |
| `POST` | `/api/zones/:name/arm`    | <Terminology title="Turning a zone's monitoring on or off" to="/docs/terminology#arm--disarm">Arm</Terminology> a <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zone</Terminology> by name.                                                                                                                                               |
| `POST` | `/api/zones/:name/disarm` | <Terminology title="Turning a zone's monitoring on or off" to="/docs/terminology#arm--disarm">Disarm</Terminology> a <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zone</Terminology> by name.                                                                                                                                            |
| `GET`  | `/api/events`             | Replay the <Terminology title="Record every motion and arm/disarm change passes through" to="/docs/terminology#event-stream">event stream</Terminology>.                                                                                                                                                                                                                                            |
| `GET`  | `/api/history`            | Read the <Terminology title="Queryable ledger of every recorded motion and change" to="/docs/terminology#sensor-history">sensor history</Terminology> ledger.                                                                                                                                                                                                                                       |
| `GET`  | `/api/mode`               | Get the current household mode.                                                                                                                                                                                                                                                                                                                                                                     |
| `POST` | `/api/mode`               | Set <Terminology title="Tightened rule set entered for a fixed date range" to="/docs/terminology#travel-mode">travel</Terminology>, bedtime, or normal mode.                                                                                                                                                                                                                                        |

## Example

```bash
curl https://lantern.local/api/zones \
  -H "Authorization: Bearer $LANTERN_TOKEN"
```

The response lists every <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zone</Terminology>, its devices, and whether it is currently <Terminology title="Turning a zone's monitoring on or off" to="/docs/terminology#arm--disarm">armed</Terminology>. Nothing more, nothing louder.
