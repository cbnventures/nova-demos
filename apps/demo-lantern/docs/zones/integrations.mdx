# Integrations

<Terminology title="Whole-house monitoring toolkit signaling with warm light" to="/docs/terminology#lantern">Lantern</Terminology> speaks HomeKit first. Beyond that, it speaks softly to the things that already live in the house.

## Built-in integrations

- **<Terminology title="Apple hub Lantern pairs with during setup" to="/docs/terminology#homekit-home-hub">HomeKit Home Hub</Terminology>** — the primary hub, paired during setup
- **Threadbare** — for repository-driven automations the household maintains
- **<Terminology title="Small HTTP API Lantern exposes for zones and events" to="/docs/terminology#spoke">Spoke</Terminology>** — to relay events to internal endpoints
- **Canary** — for notifications that should never be louder than necessary

## Custom integrations

Any HomeKit-compatible accessory can be added to a <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zone</Terminology>. <Terminology title="Whole-house monitoring toolkit signaling with warm light" to="/docs/terminology#lantern">Lantern</Terminology> does not require certification — it requires that the device knows how to be quiet.

## Configuring an integration

```bash
lantern integration add canary --topic perimeter-evenings
```

Each integration receives only the events it asked for. Nothing is broadcast.
