# Installation

<Terminology title="Whole-house monitoring toolkit signaling with warm light" to="/docs/terminology#lantern">Lantern</Terminology> installs from the <Terminology title="Package registry Lantern can be installed from" to="/docs/terminology#loom-registry">Loom Registry</Terminology> or as a <Terminology title="Container image format Lantern ships as" to="/docs/terminology#vial">Vial</Terminology> container. Pick the path your hub already trusts.

## Prerequisites

- A <Terminology title="Apple hub Lantern pairs with during setup" to="/docs/terminology#homekit-home-hub">HomeKit Home Hub</Terminology> on the network
- <Terminology title="CLI package manager used to install Lantern" to="/docs/terminology#spark">Spark</Terminology> 3.0 or later (for CLI installation)
- A quiet ten minutes — most installs finish before the kettle does

## Install via Spark

```bash title="Install Lantern"
spark install lantern
```

Verify the install:

```bash
lantern --version
```

## Install via Vial

```bash title="Pull the Lantern image"
vial pull lantern/cli:latest
```

Run inside the home network's container plane. <Terminology title="Whole-house monitoring toolkit signaling with warm light" to="/docs/terminology#lantern">Lantern</Terminology> keeps to its own room.
