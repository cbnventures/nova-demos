# Your First Watch

A first <Terminology title="General term for an active monitoring session" to="/docs/terminology#watch">watch</Terminology> is the smallest possible perimeter: one <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zone</Terminology>, one device, one quiet evening.

## Step 1: Discover the Hub

```bash
lantern hub discover
```

<Terminology title="Whole-house monitoring toolkit signaling with warm light" to="/docs/terminology#lantern">Lantern</Terminology> locates the <Terminology title="Apple hub Lantern pairs with during setup" to="/docs/terminology#homekit-home-hub">HomeKit Home Hub</Terminology> on the network and pairs without a fuss.

## Step 2: Name a Zone

```bash
lantern zone create perimeter --device front-door
```

A <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zone</Terminology> with one device is still a <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zone</Terminology>. <Terminology title="Whole-house monitoring toolkit signaling with warm light" to="/docs/terminology#lantern">Lantern</Terminology> treats it the same way it treats the whole house.

## Step 3: Arm It

```bash
lantern arm perimeter
```

The front door is <Terminology title="General term for an active monitoring session" to="/docs/terminology#watch">watched</Terminology>. <Terminology title="Whole-house monitoring toolkit signaling with warm light" to="/docs/terminology#lantern">Lantern</Terminology> says nothing until something happens, and even then, gently.

## What Just Happened

You discovered a hub, named a <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zone</Terminology>, and <Terminology title="Turning a zone's monitoring on or off" to="/docs/terminology#arm--disarm">armed</Terminology> it. The porch is now part of the <Terminology title="General term for an active monitoring session" to="/docs/terminology#watch">watch</Terminology>.
