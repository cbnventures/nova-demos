# Travel Mode

<Terminology title="Tightened rule set entered for a fixed date range" to="/docs/terminology#travel-mode">Travel mode</Terminology> tightens the rules. Quiet <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zones</Terminology> become <Terminology title="Default zone covering sleeping areas after dark" to="/docs/terminology#watch">Watch</Terminology> <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zones</Terminology>. Bedtime windows close. The porch light learns to be a little more suspicious for a few days.

## Entering travel mode

```bash
lantern mode travel --until 2026-05-01
```

The end date is mandatory. <Terminology title="Whole-house monitoring toolkit signaling with warm light" to="/docs/terminology#lantern">Lantern</Terminology> will not stay watchful longer than you ask.

## What changes

- **Quiet <Terminology title="Named area Lantern arms, disarms, and watches together" to="/docs/terminology#zone">zones</Terminology>** are <Terminology title="Turning a zone's monitoring on or off" to="/docs/terminology#arm--disarm">armed</Terminology> continuously
- **<Terminology title="Directional certainty attached to a motion event" to="/docs/terminology#confidence-band">Confidence bands</Terminology>** narrow — small movements count
- **<Terminology title="Lets a trusted person disarm without your phone" to="/docs/terminology#handoff">Handoffs</Terminology>** require an explicit passphrase
- **Notifications** route to a single trusted hub

## Returning home

<Terminology title="Tightened rule set entered for a fixed date range" to="/docs/terminology#travel-mode">Travel mode</Terminology> ends on the date you set, or sooner if you <Terminology title="Turning a zone's monitoring on or off" to="/docs/terminology#arm--disarm">arm</Terminology> `home` on a recognized device. <Terminology title="Whole-house monitoring toolkit signaling with warm light" to="/docs/terminology#lantern">Lantern</Terminology> softens automatically.
