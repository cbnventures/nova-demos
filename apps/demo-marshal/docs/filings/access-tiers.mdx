# Access Tiers

<Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> classifies every incoming request into an <Terminology title="Sponsor, Contributor, or Public classification on a request" to="/docs/terminology#access-tier">access tier</Terminology>. <Terminology title="Sponsor, Contributor, or Public classification on a request" to="/docs/terminology#access-tier">Tiers</Terminology> are not negotiable — they are <Terminology title="Mark Marshal leaves each time it acts" to="/docs/terminology#stamp">stamped</Terminology> on receipt and routed accordingly.

## The three tiers

- **Sponsor** — the queue is short, the <Terminology title="Marshal instance that handled a docket entry" to="/docs/terminology#clerk">clerk</Terminology> responds first
- **Contributor** — the queue is the working order, by <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">file</Terminology> date
- **Public** — the queue is patient, but never silent

## How the stamp is applied

```bash
marshal classify --by github-sponsor,github-org-member
```

<Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> reads the requester's status, applies the tier <Terminology title="Mark Marshal leaves each time it acts" to="/docs/terminology#stamp">stamp</Terminology>, and routes to the appropriate folder. The <Terminology title="Mark Marshal leaves each time it acts" to="/docs/terminology#stamp">stamp</Terminology> itself is <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">filed</Terminology> in the <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology>.

## Tier overrides

```bash
marshal override request-id 4821 --tier contributor --reason "former maintainer"
```

Every <Terminology title="Per-repository exception that supersedes an org-wide policy" to="/docs/terminology#override">override</Terminology> is a line in the <Terminology title="Org-wide record joining every repository's docket" to="/docs/terminology#ledger">ledger</Terminology>. <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> does not forget who asked for the exception, or why.
