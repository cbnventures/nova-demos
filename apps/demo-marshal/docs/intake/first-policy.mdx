# Your First Policy

A first <Terminology title="Sealed rule telling Marshal how to handle events" to="/docs/terminology#policy">policy</Terminology> is a single <Terminology title="Marshal's closing mark once a condition is met" to="/docs/terminology#seal">sealed</Terminology> document about a single class of events. Start small, <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">file</Terminology> once, watch the <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology> fill in.

## Step 1: Write the Policy

```yaml title="policies/stale-threads.yml"
policy: thread-archival
applies_to: ["issues", "pull-requests"]
condition:
  inactive_days: 365
action: seal
notice: "Archived after a year of silence. Reopen by request."
```

## Step 2: File It

```bash
marshal file policies/stale-threads.yml
```

<Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> <Terminology title="Mark Marshal leaves each time it acts" to="/docs/terminology#stamp">stamps</Terminology> the <Terminology title="Sealed rule telling Marshal how to handle events" to="/docs/terminology#policy">policy</Terminology> with a <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">filing</Terminology> number and adds it to the <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology>.

## Step 3: Watch the Stamp

```bash
marshal docket tail
```

The next time a stale thread crosses the threshold, <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> <Terminology title="Marshal's closing mark once a condition is met" to="/docs/terminology#seal">seals</Terminology> it. Every action is a line in the public <Terminology title="Org-wide record joining every repository's docket" to="/docs/terminology#ledger">ledger</Terminology>.

## What Just Happened

You <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">filed</Terminology> a <Terminology title="Sealed rule telling Marshal how to handle events" to="/docs/terminology#policy">policy</Terminology>, watched the <Terminology title="Mark Marshal leaves each time it acts" to="/docs/terminology#stamp">stamp</Terminology>, and read the <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology>. Everything that follows is paperwork — but <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> does the paperwork.
