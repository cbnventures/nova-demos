# Installation

<Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> installs from <Terminology title="CLI package manager used to install Marshal" to="/docs/terminology#spark">Spark</Terminology> or as a <Terminology title="Container image format Marshal ships as" to="/docs/terminology#vial">Vial</Terminology> container. Either way, it arrives with its own letterhead.

## Prerequisites

- <Terminology title="CLI package manager used to install Marshal" to="/docs/terminology#spark">Spark</Terminology> 3.0 or later
- A repository (or several) that wants supervision
- An afternoon. The first install always runs longer than expected — there is paperwork.

## Install via Spark

```bash title="Install Marshal"
spark install marshal
```

Verify the install:

```bash
marshal --version
```

## Install via Vial

```bash title="Pull the Marshal image"
vial pull marshal/cli:latest
```

The container ships with the <Terminology title="Marshal's closing mark once a condition is met" to="/docs/terminology#seal">seal</Terminology> already pressed. <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> is ready to <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">file</Terminology> the moment it lands.
