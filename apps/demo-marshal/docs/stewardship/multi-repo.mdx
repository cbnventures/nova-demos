# Multi-Repository

This is <Terminology title="Single Marshal instance supervising many repositories at once" to="/docs/terminology#multi-repository">multi-repository</Terminology> supervision: a single <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> instance across dozens of repositories, each keeping its own <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology>. <Terminology title="Sealed rule telling Marshal how to handle events" to="/docs/terminology#policy">Policies</Terminology> <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">file</Terminology> once and apply everywhere they are valid.

## Filing across repositories

```yaml title="policies/org-wide-archival.yml"
policy: thread-archival
applies_to: ["issues", "pull-requests"]
repositories: ["org/*"]
condition:
  inactive_days: 365
action: seal
```

The `repositories` field accepts wildcards. <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> expands the list at <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">filing</Terminology> time and <Terminology title="Mark Marshal leaves each time it acts" to="/docs/terminology#stamp">stamps</Terminology> the <Terminology title="Sealed rule telling Marshal how to handle events" to="/docs/terminology#policy">policy</Terminology> into each <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology> separately.

## Per-repository overrides

A repository can <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">file</Terminology> an <Terminology title="Per-repository exception that supersedes an org-wide policy" to="/docs/terminology#override">override</Terminology> that supersedes the org-wide <Terminology title="Sealed rule telling Marshal how to handle events" to="/docs/terminology#policy">policy</Terminology>:

```yaml title="repos/org/critical-service/policies/no-archival.yml"
override: thread-archival
reason: "Long-running design discussions are normal here."
```

<Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> reads the <Terminology title="Per-repository exception that supersedes an org-wide policy" to="/docs/terminology#override">override</Terminology>, <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">files</Terminology> it under the repository's <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology>, and stops applying the parent rule for that repo.

## Reading the org-wide ledger

```bash
marshal docket list --org acme --since 30d
```

<Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> joins every repository <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology> into a single ordered <Terminology title="Org-wide record joining every repository's docket" to="/docs/terminology#ledger">ledger</Terminology>. <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">Filed</Terminology> in triplicate, even when there are forty repositories.
