# Scheduled Stewardship

<Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology>'s scheduled <Terminology title="Marshal's scheduled maintenance run without manual work" to="/docs/terminology#stewardship">stewardship</Terminology> runs on a cron. Cleanups, audits, rollovers, label sweeps — anything that should happen at the top of the hour without anyone being woken up.

## What can be scheduled

- **Cleanups** — close and <Terminology title="Marshal's closing mark once a condition is met" to="/docs/terminology#seal">seal</Terminology> threads that meet a <Terminology title="Sealed rule telling Marshal how to handle events" to="/docs/terminology#policy">policy</Terminology> condition
- **Audits** — verify that every open ticket has been classified
- **Rollovers** — roll the <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology> forward into the next quarter
- **Label sweeps** — apply or remove labels in bulk

## Filing a scheduled job

```yaml title="schedules/quarterly-rollover.yml"
schedule: "0 0 1 1,4,7,10 *"
action: rollover
docket: "FY-{quarter}"
notice: "Rolled forward at the top of the quarter."
```

## Watching the cron

```bash
marshal cron list
```

<Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> lists every scheduled job, its next run, and the <Terminology title="Sealed rule telling Marshal how to handle events" to="/docs/terminology#policy">policy</Terminology> that <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">filed</Terminology> it. Nothing runs <Terminology title="Marshal's closing mark once a condition is met" to="/docs/terminology#seal">unsealed</Terminology>.
