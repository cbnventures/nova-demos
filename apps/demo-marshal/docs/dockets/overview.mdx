# Dockets

A <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology> is the public record of every action <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> has taken on a repository. Every closed thread, every <Terminology title="Mark Marshal leaves each time it acts" to="/docs/terminology#stamp">stamped</Terminology> approval, every scheduled rollover writes a line here.

## Docket entries

- **<Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">FILED</Terminology>** — a workflow was queued for execution
- **<Terminology title="Mark Marshal leaves each time it acts" to="/docs/terminology#stamp">STAMPED</Terminology>** — <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> acted, and the result is now part of the record
- **RECEIVED** — incoming work, awaiting tier classification
- **ARCHIVED** — a thread was <Terminology title="Marshal's closing mark once a condition is met" to="/docs/terminology#seal">sealed</Terminology>; the case is closed

The <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology> is append-only. <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> does not retract. <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> amends only by <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">filing</Terminology> a new entry.
