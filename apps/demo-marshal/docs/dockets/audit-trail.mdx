# Audit Trail

The <Terminology title="Docket read end to end with the clerk attached" to="/docs/terminology#audit-trail">audit trail</Terminology> is the <Terminology title="Append-only public record of every Marshal action" to="/docs/terminology#docket">docket</Terminology>, read end to end. Every <Terminology title="Mark Marshal leaves each time it acts" to="/docs/terminology#stamp">stamp</Terminology>, every <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">filing</Terminology>, every <Terminology title="Per-repository exception that supersedes an org-wide policy" to="/docs/terminology#override">override</Terminology> — in the order they happened, with the <Terminology title="Marshal instance that handled a docket entry" to="/docs/terminology#clerk">clerk</Terminology>'s signature attached.

## Reading the trail

```bash
marshal audit --since 90d --format ledger
```

Output is a single chronological column. No summaries, no rollups. The trail is meant to be read, not skimmed.

## What the trail captures

| Field       | Description                                                                                                                                                                                                                                                                                                                                                                                          |
|-------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `timestamp` | When <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> acted, to the second.                                                                                                                                                                                                                              |
| `clerk`     | Which <Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> instance handled the entry.                                                                                                                                                                                                                       |
| `action`    | <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">FILED</Terminology>, <Terminology title="Mark Marshal leaves each time it acts" to="/docs/terminology#stamp">STAMPED</Terminology>, RECEIVED, ARCHIVED, <Terminology title="Per-repository exception that supersedes an org-wide policy" to="/docs/terminology#override">OVERRIDDEN</Terminology>. |
| `policy`    | The <Terminology title="Sealed rule telling Marshal how to handle events" to="/docs/terminology#policy">policy</Terminology> that authorized the action.                                                                                                                                                                                                                                             |
| `subject`   | The repository and thread the action applied to.                                                                                                                                                                                                                                                                                                                                                     |
| `seal`      | A signed hash linking this entry to the previous one.                                                                                                                                                                                                                                                                                                                                                |

## Exporting for review

```bash
marshal audit --export quarterly-2026-q1.pdf
```

<Terminology title="Automated repository governance system filing and sealing policies" to="/docs/terminology#marshal">Marshal</Terminology> generates a printable PDF with the <Terminology title="Marshal's closing mark once a condition is met" to="/docs/terminology#seal">seal</Terminology> of office at the top of every page. Suitable for <Terminology title="Submitting a policy or job to Marshal's docket" to="/docs/terminology#filing">filing</Terminology>.
