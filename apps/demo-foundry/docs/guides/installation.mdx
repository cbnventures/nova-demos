# Installation

This guide walks you through installing Foundry and verifying your environment. The whole process takes under two minutes.

## Prerequisites

Before installing Foundry, ensure your environment meets these requirements:

| Requirement                                                                                                                      | Version | Notes                                                                                                                                                                                                                                                                                      |
|----------------------------------------------------------------------------------------------------------------------------------|---------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **<Terminology title="CLI runtime distributing the Foundry CLI and sub-tools" to="/docs/terminology#spark">Spark</Terminology>** | `>=3.0` | The Foundry CLI is distributed through <Terminology title="CLI runtime distributing the Foundry CLI and sub-tools" to="/docs/terminology#spark">Spark</Terminology>.                                                                                                                       |
| **<Terminology title="Primary language declared for a Foundry workspace" to="/docs/terminology#alloy">Alloy</Terminology>**      | `>=5.0` | Required for type-aware <Terminology title="Foundry's linting engine with 380+ rules" to="/docs/terminology#warden">Warden</Terminology> rules and <Terminology title="Generates test scaffolds from exported type signatures" to="/docs/terminology#crucible">Crucible</Terminology>.     |
| **<Terminology title="Optional secondary language runtime for a workspace" to="/docs/terminology#ferric">Ferric</Terminology>**  | `>=1.8` | Optional. Only needed for <Terminology title="Optional secondary language runtime for a workspace" to="/docs/terminology#ferric">Ferric</Terminology> <Terminology title="Foundry project declared in a .grain manifest" to="/docs/terminology#workspace">workspace</Terminology> targets. |

:::warning
Foundry 2.x requires <Terminology title="Primary language declared for a Foundry workspace" to="/docs/terminology#alloy">Alloy</Terminology> 5.0 or later. Earlier versions of <Terminology title="Primary language declared for a Foundry workspace" to="/docs/terminology#alloy">Alloy</Terminology> do not support the type introspection API that <Terminology title="Generates test scaffolds from exported type signatures" to="/docs/terminology#crucible">Crucible</Terminology> uses to generate test scaffolds.

If you are running <Terminology title="Primary language declared for a Foundry workspace" to="/docs/terminology#alloy">Alloy</Terminology> 4.x, upgrade before installing Foundry.
:::

## Install Foundry

<Tabs>
<TabItem value="spark" label="Spark" default>

The recommended way to install Foundry is through <Terminology title="CLI runtime distributing the Foundry CLI and sub-tools" to="/docs/terminology#spark">Spark</Terminology>:

```bash title="Global install via Spark"
spark install foundry
```

This installs the `foundry` CLI binary and all sub-tools (<Terminology title="Foundry's core CLI that forges the workspace" to="/docs/terminology#anvil">Anvil</Terminology>, <Terminology title="Resolves the dependency graph with query tools" to="/docs/terminology#tongs">Tongs</Terminology>, <Terminology title="Content-addressable build cache skipping unchanged packages" to="/docs/terminology#quench">Quench</Terminology>, <Terminology title="Parallel task runner building independent packages together" to="/docs/terminology#bellows">Bellows</Terminology>, <Terminology title="Generates test scaffolds from exported type signatures" to="/docs/terminology#crucible">Crucible</Terminology>, and <Terminology title="Scans the workspace for dead code and unused exports" to="/docs/terminology#slag">Slag</Terminology>) as a single package.

</TabItem>
<TabItem value="loom" label="Loom Registry">

You can also install Foundry from the <Terminology title="Alternate package source for a pinned Foundry install" to="/docs/terminology#loom">Loom Registry</Terminology> as a <Terminology title="Foundry project declared in a .grain manifest" to="/docs/terminology#workspace">workspace</Terminology> dependency:

```bash title="Workspace dependency via Loom"
loom add --dev foundry
```

This is useful when you want to pin a specific Foundry version per <Terminology title="Foundry project declared in a .grain manifest" to="/docs/terminology#workspace">workspace</Terminology> rather than using a global install.

</TabItem>
<TabItem value="vial" label="Vial Container">

For <Terminology title="CI environment Foundry integrates with" to="/docs/terminology#conduit">Conduit</Terminology> pipelines and reproducible environments, use the official <Terminology title="Container runtime for a reproducible Foundry environment" to="/docs/terminology#vial">Vial</Terminology> image:

```bash title="Pull the official Vial image"
vial pull foundry/cli:latest
vial run foundry/cli:latest foundry --version
```

The <Terminology title="Container runtime for a reproducible Foundry environment" to="/docs/terminology#vial">Vial</Terminology> image includes <Terminology title="CLI runtime distributing the Foundry CLI and sub-tools" to="/docs/terminology#spark">Spark</Terminology>, <Terminology title="Primary language declared for a Foundry workspace" to="/docs/terminology#alloy">Alloy</Terminology>, and Foundry pre-installed. It is the recommended approach for <Terminology title="CI environment Foundry integrates with" to="/docs/terminology#conduit">Conduit</Terminology> stages that run `foundry ignite` as part of a deployment pipeline.

</TabItem>
</Tabs>

## Verify Installation

Confirm everything is working:

```bash title="Check the installed version"
foundry --version
```

Expected output:

```text
Foundry CLI v2.4.1
  Anvil    2.4.1
  Tongs    2.4.1
  Quench   2.4.1
  Bellows  2.4.1
  Crucible 2.4.1
  Slag     2.4.1
```

:::info
All sub-tools ship at the same version as the main CLI. There is no version matrix to manage — one install, one version number, all tools aligned.
:::

## Post-Install Configuration

Foundry does not require a global configuration file. All settings live in your <Terminology title="Foundry project declared in a .grain manifest" to="/docs/terminology#workspace">workspace</Terminology> <Terminology title="Single source of truth for a Foundry workspace" to="/docs/terminology#grain-manifest">`.grain` manifest</Terminology>.

However, you can set two optional environment variables:

| Variable              | Purpose                                                                                                                                                             | Default          |
|-----------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------|
| `FOUNDRY_CACHE_DIR`   | Location of the <Terminology title="Content-addressable build cache skipping unchanged packages" to="/docs/terminology#quench">Quench</Terminology> build cache.    | `.foundry/cache` |
| `FOUNDRY_PARALLELISM` | Maximum concurrent tasks for <Terminology title="Parallel task runner building independent packages together" to="/docs/terminology#bellows">Bellows</Terminology>. | Auto (CPU cores) |
