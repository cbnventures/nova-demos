# Getting Started

Foundry is a compiler for developer intent. You describe what your <Terminology title="Foundry project declared in a .grain manifest" to="/docs/terminology#workspace">workspace</Terminology> should look like in a single <Terminology title="Single source of truth for a Foundry workspace" to="/docs/terminology#grain-manifest">`.grain` manifest</Terminology>, and Foundry <Terminology title="Running foundry ignite to generate workspace artifacts" to="/docs/terminology#forge--ignite">forges</Terminology> the entire development environment — directory structure, dependency graph, build pipeline, linting rules, and test scaffolds.

No configuration files. No manual wiring. One manifest in, a full environment out.

## What Foundry Does

Foundry reads a <Terminology title="Single source of truth for a Foundry workspace" to="/docs/terminology#grain-manifest">`.grain` manifest</Terminology> and produces everything a multi-package <Terminology title="Foundry project declared in a .grain manifest" to="/docs/terminology#workspace">workspace</Terminology> needs to build, lint, test, and deploy. Instead of maintaining dozens of configuration files across packages, you maintain one file that declares your intent.

## Quick Start

Install Foundry globally via <Terminology title="CLI runtime distributing the Foundry CLI and sub-tools" to="/docs/terminology#spark">Spark</Terminology>:

```bash title="Install Foundry"
spark install foundry
```

Create a minimal <Terminology title="Single source of truth for a Foundry workspace" to="/docs/terminology#grain-manifest">`.grain` manifest</Terminology> in your project root:

```text title="project.grain"
workspace "my-app" {
  lang   = "alloy"
  warden = ["strict"]

  packages {
    core { type = "library" }
    api  { type = "service", depends = ["core"] }
  }
}
```

<Terminology title="Running foundry ignite to generate workspace artifacts" to="/docs/terminology#forge--ignite">Forge</Terminology> the <Terminology title="Foundry project declared in a .grain manifest" to="/docs/terminology#workspace">workspace</Terminology>:

```bash title="Run your first forge"
foundry ignite
```

Foundry reads the manifest, resolves the dependency graph, generates <Terminology title="Foundry's linting engine with 380+ rules" to="/docs/terminology#warden">Warden</Terminology> rules, scaffolds test files, and writes every configuration artifact your packages need.

:::tip
Run `foundry ignite --dry-run` to preview what Foundry will generate without writing any files to disk. This is the fastest way to validate a manifest before committing.
:::
